# Frontend Mentor - Social Links Profile

This is my solution to the [Social Links Profile challenge on Frontend Mentor](https://www.frontendmentor.io/).

## Overview

### The Challenge

The goal of this project is to build a social links profile that allows users to view a person's profile information and access their social media links.

## Features

- Responsive profile card layout
- Circular profile image
- Profile name and location
- Short personal description
- Social media links
- Dark background with contrasting text and buttons

## What I Learned

While building this project, I practised:

- Structuring a webpage using HTML.
- Using CSS Flexbox to align and position elements.
- Styling profile images with `border-radius`.
- Managing spacing with `margin`, `padding`, and `gap`.
- Applying custom fonts using Google Fonts.
- Styling links and creating consistent button layouts.

## Getting Started

To run this project locally:

1. Clone this repository or download the project files.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
